  3. 再次保存

🔄 與遊戲集成
═══════════════════════════════════════════════════════════════════════

基本步驟

1. 加載地圖配置：
   TilemapConfig config = new TilemapConfig(80, 18);
   config.load();

2. 遍歷瓷磚：
   for (int y = 0; y < 18; y++) {
       for (int x = 0; x < 80; x++) {
           int tileIndex = config.getTile(x, y);
           if (tileIndex >= 0) {
               renderTile(x, y, tileIndex);
           }
       }
   }

3. 在遊戲中使用瓷磚數據進行渲染、碰撞檢測等

📞 常見問題
═══════════════════════════════════════════════════════════════════════

Q: 無法導入圖像？
A: 確保文件格式為 PNG/JPG/BMP，且有讀取權限

Q: 瓷磚顯示不正確？
A: 調整瓷磚大小滑塊，確保與圖像尺寸相符

Q: 如何改變地圖大小？
A: 編輯 TilemapEditorGUI.java 中的常數並重新編譯

Q: 地圖文件存在哪裡？
A: 保存為 tilemap_config.dat（工作目錄）
