## 💾 數據存儲

地圖保存為 `tilemap_config.dat` (二進制格式)：

```
[檔案頭]
width: int (80)
height: int (18)

[地圖數據]
tiles[0][0]: int (瓷磚索引或 -1)
tiles[0][1]: int
...
tiles[17][79]: int
```

## 🔄 集成到遊戲

### 基本步驟

```java
// 1. 加載地圖配置
TilemapConfig tilemapConfig = new TilemapConfig(80, 18);
tilemapConfig.load();

// 2. 遍歷並渲染瓷磚
for (int y = 0; y < 18; y++) {
    for (int x = 0; x < 80; x++) {
        int tileIndex = tilemapConfig.getTile(x, y);
        if (tileIndex >= 0) {
            // 根據索引渲染對應的瓷磚
            renderTile(x, y, tileIndex);
        }
    }
}
```
